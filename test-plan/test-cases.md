# Test Cases

This project focuses on automated testing.  
Test cases are implemented directly as automated smoke tests using Playwright.

## Automated Smoke Test Coverage

| Test Case | Description |
|---------|-------------|
| Login Smoke Test | Validates user can log in with valid credentials |
| Products Smoke Test | Validates product catalog is visible after login |
| Add to Cart Smoke Test | Validates a product can be added to the cart |
| Checkout Smoke Test | Validates full checkout process end-to-end |

Detailed test steps and validations are implemented directly in the automated test files.
