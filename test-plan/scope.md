# Test Scope

## In Scope
The following functional areas are included in the testing scope:

- User authentication (login with valid credentials)
- Product catalog visualization
- Add product to shopping cart
- Shopping cart management
- Checkout process
- Order completion confirmation

The scope focuses on validating the main End-to-End business flow of the application through automated smoke tests.

## Out of Scope
The following areas are intentionally excluded from the current scope:

- Performance and load testing
- Security testing
- API testing
- Accessibility testing
- Mobile and responsive testing
- Cross-browser visual validation
- Negative and edge case scenarios

These areas are excluded to keep the focus on high-value automated smoke testing.
